## Рекомендации по безопасности

### SSH ключи
- Никогда не коммитьте приватные ключи
- Используйте `id_ed25519` (Ed25519) вместо `id_rsa`
- Ограничьте права: `chmod 600 ~/.ssh/id_ed25519`

### Docker
- Не храните секреты в Dockerfile
- Используйте `.env` файлы (добавлены в `.gitignore`)
- Обновляйте базовые образы регулярно

### Сеть
- Livox LiDAR должен быть в изолированной подсети
- Не открывайте порты 11311, 9090 наружу без авторизации
- Используйте VPN/Tailscale для удалённого доступа

### Конфигурация
- Файлы с реальными ключами (`livox_lidar_config.json`, VPN конфиги) **НЕ коммитить**
- Используйте `.example` шаблоны
- Добавьте чувствительные файлы в `.gitignore`

## Известные ограничения

- ROS1 Noetic не поддерживает аутентификацию топиков по умолчанию
- ROS Bridge WebSocket не имеет встроенной авторизации
- Для production рекомендуется настроить `rosauth`
